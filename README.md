# Malandragem Capoeira

Página única em HTML e Tailwind CSS, com imagens e CSS locais. Sem instalação ou etapa de compilação.

## Visualizar
Abra `index.html` no navegador. Alternativamente, execute nesta pasta:

    python3 -m http.server 8080

Acesse http://localhost:8080.

Criar um repositório público e enviar o conteúdo desta pasta para a raiz. Em Settings > Pages, selecionar Deploy from a branch, branch main e pasta / (root). O GitHub fornecerá a URL HTTPS. Os caminhos relativos suportam publicação em subdiretórios.
